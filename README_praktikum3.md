## Deskripsi Tugas

Praktikum 3 mata kuliah Pemrograman Web berfokus pada pembuatan **HTML Form**.
Terdapat dua tugas dalam praktikum ini — form pendaftaran sebagai latihan dasar
dan form pemesanan sebagai kuis yang menggunakan layout tabel.

---

## Dokumentasi

### 📄 index.html — Form Pendaftaran

Form pendaftaran anggota sederhana dengan struktur linear.

| Field | Tipe Elemen |
|---|---|
| Nama lengkap | `<input type="text">` |
| Email | `<input type="email">` |
| Password | `<input type="password">` |
| Jenis Kelamin | `<input type="radio">` — Pria / Wanita |
| Hobi | `<input type="checkbox">` — Olahraga, Seni, Sains, Bahasa |
| Kota | `<select>` — Lampung, Banyumas, Aceh, Bandung, Semarang, Purbalingga |
| Pesan | `<textarea>` |
| Aksi | Tombol **Daftar** (submit) & **Reset** |

---

### 📄 kuis.html — Form Pemesanan

Form pemesanan makanan menggunakan layout `<table>` untuk penataan field yang lebih rapi.

| Field | Tipe Elemen |
|---|---|
| Nama lengkap | `<input type="text">` |
| Nomor telepon | `<input type="number">` — placeholder `62 ...` |
| Alamat pemesan | `<textarea>` |
| Makanan | `<input type="checkbox">` — Mie Ayam, Mie Goreng, Mie Tekwan, Mie Shoun |
| Ukuran pesanan | `<input type="radio">` — S, M, L, XL, XXL |
| Jumlah pesanan | `<input type="number">` |
| Metode masak | `<select>` — Slow Cook, Well Done, Express |
| Catatan tambahan | `<textarea>` |
| Aksi | Tombol **Kirim** (submit) & **Hapus Ulang** (reset) |
